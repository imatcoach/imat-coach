IMAT COACH — مستقل از B12

این پوشه شامل یک سایت استاتیک مستقل است.

ساختار اصلی:
- index.html: صفحه اصلی
- imat.html: معرفی IMAT
- universities.html: دیتابیس ظرفیت‌های رسمی 2026 با فیلتر
- cutoffs.html: چارچوب دیتابیس cutoff تاریخی
- scholarships.html: بورسیه‌ها + صفحات منطقه‌ای
- students.html: برنامه پایه‌های 7،8،10،11
- admissions.html: نقشه راه اپلای
- courses/: صفحات پزشکی، دندانپزشکی، دامپزشکی
- regions/: صفحات اختصاصی مناطق
- guides/: کنکور + IMAT
- assets/imat-coach-logo.png: لوگوی نهایی بدون تصویر انسان
- sitemap.xml / robots.txt: SEO
- CNAME.example: نام دامنه‌ای که بعد از ثبت می‌توانی برای GitHub Pages استفاده کنی

دامنه هدف: https://imatmoshavereh.ir/

منبع ظرفیت‌های 2026:
MUR D.M. 1005 del 06-08-2026, Tabella B
https://www.mur.gov.it/sites/default/files/2026-08/Decreto%20Ministeriale%20n.%201005%20Tabella%20B%20posti.pdf

نکته: cutoff نهایی 2026 در این نسخه عمداً قطعی نشده است.

انتشار رایگان:
1) یک repository عمومی GitHub بساز.
2) محتوای این پوشه را در repository قرار بده.
3) Settings > Pages > Deploy from branch.
4) وقتی دامنه را ثبت کردی، در Pages > Custom domain، imatmoshavereh.ir را وارد کن و DNS را طبق راهنمای GitHub تنظیم کن.

گزینه جایگزین: Cloudflare Pages.

برای ثبت .ir از سامانه ایرنیک/ثبت‌کننده مجاز استفاده کن. ثبت دامنه باید به نام خود صاحب برند باشد.
